## What's missing

The managed guidance block aiwf writes into `AGENTS.md` embeds the version of
the binary that rendered it, and `AGENTS.md` is a tracked root file. Any
`aiwf update` run from a binary of a different version rewrites that line, so a
tracked file comes back modified with no content change behind it.

`internal/initrepo/agents_guidance.go:40` passes `version.Current().Version`
into `skills.RenderCodexGuidance`, whose output is inlined into `AGENTS.md`. The
Claude route stamps the same version through `skills.MaterializeGuidance`
(`internal/skills/guidance.go`), called from `internal/initrepo/initrepo.go`,
which writes `.claude/aiwf-guidance.md`; that file is gitignored, so the same stamp there is
invisible to git. The tracked surface is what differs between the two hosts, not
the stamping.

Measured on Linux against two clean clones of commit `4f8ec4d445e08edf06dc388e9d3b8fb8839e7bf8`:

```
$ aiwf update --root <clone-a>            # binary that generated the committed block
$ git -C <clone-a> status --porcelain
                                          # (empty)

$ go build -o aiwf-v999 -ldflags="-X .../internal/version.Stamp=v9.9.9" ./cmd/aiwf
$ ./aiwf-v999 update --root <clone-b>
$ git -C <clone-b> status --porcelain
 M AGENTS.md

$ git -C <clone-b> diff AGENTS.md
-<!-- aiwf guidance — generated by aiwf; do not edit. aiwf-version: v0.37.1-0.20260923015904-5b1127c25fc5 -->
+<!-- aiwf guidance — generated by aiwf; do not edit. aiwf-version: v9.9.9 -->
```

Expected an update that changes no guidance content to leave the tree clean.
Observed the stamp line rewritten and nothing else. The installed release
`v0.37.0` reproduces it the same way, so this is not specific to a development
build.

## Why it matters

`guidance.wire_agentsmd` defaults to true, so every consumer repository with
Codex selected carries this block in a tracked file. Two people whose aiwf
versions differ will each see the line change under them and commit it back,
indefinitely — a tracked file that cannot come to rest while the team is not on
one version.

It also costs the property the delivery is supposed to have: that an update
changing no guidance preserves bytes. That holds for the Claude route and does
not hold for the Codex route, for every version boundary rather than only at
upgrade time.
